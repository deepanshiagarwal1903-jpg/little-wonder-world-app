# Little Wonder World — Learn, Create, Grow!

A gentle, ad-free learning world for children aged 3–8, with mini-games, coloring, and a rewards garden hosted by Lumi the bunny.

**Tech:** TanStack Start, React 19, Tailwind CSS 4, TypeScript, Zod, deployed on Netlify. Progress is saved in the browser's localStorage. Nothing about the child is sent to a server.

## Run locally

```bash
pnpm install
pnpm dev   # http://localhost:3000
```
